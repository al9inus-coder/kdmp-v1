# KDMP
Kendali Digital Manajemen Pengadaan

## Tujuan

KDMP adalah sistem informasi terintegrasi untuk mendukung perencanaan, pelaksanaan, monitoring, dan pelaporan pengadaan barang/jasa pemerintah serta kegiatan swakelola.

Sistem dibangun untuk membantu:

- Pengelolaan anggaran
- Penyusunan RUP
- Pengelolaan paket pengadaan
- Monitoring realisasi
- Pengelolaan perjalanan dinas
- Pengelolaan lembur
- Pelaporan manajemen
