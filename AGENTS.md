# KDMP Agent Instructions

Project Name:
KDMP - Kendali Digital Manajemen Pengadaan

Tech Stack:
- Laravel 13
- PHP 8.4
- MySQL
- Bootstrap 5
- AdminLTE 4

Coding Rules:

1. Use Laravel conventions.
2. Use Resource Controllers.
3. Use Form Request Validation.
4. Use Eloquent Relationships.
5. Use Indonesian language for labels and UI.
6. Use Bootstrap 5 components.
7. Use pagination for index pages.
8. Avoid raw SQL unless necessary.
9. Keep controllers thin.
10. Business logic should be placed in services when complexity increases.

- Admin
- Kabid
- Staff
